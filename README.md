# 김희준 포트폴리오

사용자 경험과 기술 구조를 함께 고민하는 프론트엔드 개발자 김희준의 개인 포트폴리오입니다.

- 크래프톤 정글 12기 졸업
- 대표 프로젝트 GOPS
- 경력, 교육, 기술 스택
- GitHub Pages 자동 배포

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run build:pages
```

`main` 브랜치에 푸시하면 GitHub Actions가 정적 사이트를 GitHub Pages에 배포합니다.
